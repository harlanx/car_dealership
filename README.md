# Silvian Automobile PH
Visit the working preview on [Silvian Automobile PH](https://harlanx.github.io/car_dealership/) deployed via Github Page.

Responsive web front page layout for a car dealership company created using Dart with Flutter SDK for Web.\
Most of the UI elements has hover triggered animations and the layout adaption depends on the broswer size either dekstop or mobile.
